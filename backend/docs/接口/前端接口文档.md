## 1. 通用规范

### 1.1 认证方式

需要登录的接口在 Header 中传：

```
Authorization: Bearer <access_token>
```

登录后从返回的 `data.access_token` 获取 token。

### 1.2 响应格式

**成功：**
```json
{"code": 200, "message": "操作成功", "data": {...}}
```

**失败：**
```json
{"code": 422, "message": "验证失败", "detail": "具体错误"}
```

**未登录：**
```json
{"code": 401, "message": "请先登录后再进行操作"}
```

### 1.3 分页参数

列表接口统一支持：

| 参数 | 类型 | 默认 | 说明 |
|:---|:---|:---:|:---|
| `page` | int | 1 | 页码 |
| `page_size` | int | 20 | 每页条数（最大 100） |

分页响应：
```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "items": [...],
    "total": 50,
    "page": 1,
    "page_size": 20
  }
}
```

## 2. 用户模块

### 2.1 注册

```
POST /users/register
```

**Body：**
```json
{
  "username": "张三（2-50位，字母/数字/下划线/中文）",
  "password": "pass123（6-128位）",
  "phone": "13800138000（11位手机号）",
  "email": "user@example.com"
}
```

**返回：** `data` 为 [用户对象](#用户对象)

---

### 2.2 登录

```
POST /users/login
```

**Body：**
```json
{
  "type": "username",    // username / phone / email 三选一
  "account": "张三",     // 与 type 对应的值
  "password": "pass123"
}
```

**返回：**
```json
{
  "code": 200,
  "data": {
    "access_token": "eyJhbG...",
    "token_type": "bearer",
    "user": { /* 用户对象 */ }
  }
}
```

---

### 2.3 获取当前用户

```
GET /users/me
```

**Header：** `Authorization: Bearer <token>`

**返回：** `data` 为 [用户对象](#用户对象)。未登录时返回 `data: null`。

---

### 2.4 更新个人信息

```
PUT /users/me
```

**Header：** `Authorization: Bearer <token>`

**Body：（全部可选）**
```json
{
  "avatar": "头像URL",
  "bio": "个人简介",
  "gender": "male"   // male / female / other
}
```

---

### 2.5 获取用户公开信息

```
GET /users/{user_id}/profile
```

**返回：** `data` 为 [用户对象](#用户对象)（不包含手机号、邮箱等敏感信息）

---

### 用户对象

```json
{
  "id": 1,
  "username": "张三",
  "phone": "13800138000",
  "email": "user@example.com",
  "avatar": "URL或null",
  "bio": "简介或null",
  "gender": "male或null",
  "role": 0,
  "is_banned": false,
  "created_at": "2026-01-01T00:00:00"
}
```

## 3. 店铺模块

### 3.1 创建店铺

```
POST /shops
```

**Header：** 需登录

**Body：**
```json
{
  "name": "陈记糖水铺",
  "dict_data_ids": [1, 5],
  "menu_items": [
    {"name": "杨枝甘露", "price": 18.0, "description": "招牌"}
  ]
}
```

| 字段 | 必填 | 说明 |
|:---|:---:|:---|
| `name` | ✅ | 店铺名称（1-100字符） |
| `dict_data_ids` | ✅ | 品类ID和区域ID列表（**至少包含1个品类+1个区域**，共≥2个），从字典接口获取 |
| `menu_items` | ❌ | 初始菜单项 |

---

### 3.2 搜索店铺

```
GET /shops?keyword=糖水&page=1&page_size=20
```

**查询参数：**

| 参数 | 类型 | 说明 |
|:---|:---|:---|
| `keyword` | string | 搜索关键词（店铺名模糊匹配） |
| `category_ids` | int[] | 品类筛选（DictData ID 列表） |
| `district_ids` | int[] | 区域筛选（DictData ID 列表） |
| `min_rating` | float | 最低评分筛选（0-5） |
| `sort_by` | string | `favorite_count`（默认）/ `average_rating` / `view_count` / `created_at` |
| `sort_order` | string | `desc`（默认） / `asc` |
| `page` | int | 页码 |
| `page_size` | int | 每页条数（最大100） |

**返回：**

```json
{
  "items": [
    {
      "id": 1,
      "name": "陈记糖水铺",
      "average_rating": 4.5,
      "view_count": 100,
      "favorite_count": 20,
      "comment_count": 10,
      "dict_data": [{"id": 1, "name": "糖水", "dict_type_name": "品类"}],
      "images": [{"id": 1, "url": "..."}],
      "is_favorited": false,
      "created_at": "2026-01-01T00:00:00",
      "updated_at": "2026-01-01T00:00:00"
    }
  ],
  "total": 1, "page": 1, "page_size": 20
}
```

### 3.4 评分

```
POST /shops/{shop_id}/rating
```

**Header：** 需登录

**Body：**
```json
{"score": 4}
```

`score` 为 1-5 的整数。

### 3.5 菜单

```
GET  /shops/{shop_id}/menu      # 获取菜单列表
POST /shops/{shop_id}/menu?name=xxx&price=18&description=xxx  # 添加菜品（query参数）
```

添加菜品（需登录），参数为 query 参数：

| 参数 | 必填 | 说明 |
|:---|:---:|:---|
| `name` | ✅ | 菜品名称（1-100字符） |
| `price` | ❌ | 价格（≥0） |
| `description` | ❌ | 菜品描述（最多500字符） |

**返回：**
```json
{"code": 200, "message": "success", "data": {...}}
```

---

### 3.6 收藏

```
# 切换收藏
POST /favorites/toggle?shop_id=1

GET /favorites/user?page=1&page_size=20
# 需登录
```

**切换收藏返回：**
```json
{"code": 200, "message": "success", "data": {"is_favorited": true, "favorite_count": 10}}
```

## 4. 互动模块

### 4.1 评论

```
POST  /shops/{shop_id}/comments          # 发表评论
GET   /shops/{shop_id}/comments          # 评论列表
PUT   /comments/{comment_id}             # 更新评论
DELETE/comments/{comment_id}             # 删除评论
POST  /comments/{comment_id}/replies     # 回复评论
GET   /comments/{comment_id}/replies     # 回复列表
DELETE/replies/{reply_id}                # 删除回复
```

**发表评论 Body：** `{"content": "好吃！"}`（1-2000字符）

**回复评论参数（query）：**
| 参数 | 必填 | 说明 |
|:---|:---:|:---|
| `content` | ✅ | 回复内容（1字符以上） |
| `reply_to_user_id` | ❌ | 回复目标用户ID（用于 @username） |

---

### 4.2 问答

```
POST  /shops/{shop_id}/questions          # 提问
GET   /shops/{shop_id}/questions          # 问题列表
PUT   /questions/{question_id}             # 更新问题
DELETE/questions/{question_id}            # 删除问题
POST  /questions/{question_id}/answers    # 回答
GET   /questions/{question_id}/answers    # 回答列表
DELETE/answers/{answer_id}                # 删除回答
```

**提问参数（query）：**
| 参数 | 必填 | 说明 |
|:---|:---:|:---|
| `title` | ✅ | 问题概括（1-100字符） |
| `content` | ❌ | 问题描述（长文本） |

**回答参数（query）：**
| 参数 | 必填 | 说明 |
|:---|:---:|:---|
| `content` | ✅ | 回答内容（1字符以上） |
| `reply_to_user_id` | ❌ | 回复目标用户ID |

---

### 4.3 点赞

```
POST /likes/toggle
```

**Header：** 需登录

**Body：**
```json
{"entity_type": "shop_comment", "entity_id": 1}
```

| entity_type | 说明 |
|:---|:---|
| `shop_comment` | 一级评论 |
| `comment_reply` | 回复 |
| `shop_question` | 问题 |
| `question_answer` | 回答 |

**返回：**
```json
{"is_liked": true, "like_count": 5}
```

## 5. 消息通知模块

所有接口需登录。

```
       # 消息列表，支持筛选 unread_only 和 type
```

## 6. 字典模块

### 6.1 获取所有字典类型

```
GET /dict/types
```

**返回：** 全部字典类型列表（品类、区域、就餐方式等）

```json
[
  {"id": 1, "name": "品类", "description": "..."},
  {"id": 2, "name": "区域", "description": "..."}
]
```

### 6.2 获取字典类型详情（含数据项）

```
GET /dict/types/{type_id}
```

**返回：** 该类型及其下的所有字典数据项

### 6.3 按类型名称查字典数据

```
GET /dict/data?type_name=品类
```

**返回：**
```json
[
  {"id": 1, "name": "火锅", "dict_type_name": "品类", "extra": null},
  {"id": 2, "name": "小吃快餐", "dict_type_name": "品类", "extra": null}
```

## 11. 管理员模块

所有接口需管理员权限。

### 11.1 平台概览

```
GET /admin/overview
# 返回：平台统计数据

GET /admin/daily-trends?days=7
# 返回每日新增趋势数据（最多30天）

GET /admin/pending-counts
# 返回待处理工单数
```

### 11.2 用户管理

```
GET /admin/users?keyword=&is_active=&is_banned=&page=1&page_size=20
# 用户列表

GET /admin/users/{user_id}
# 用户详情（管理员）

POST /admin/users/{user_id}/ban?reason=违规内容
# 封禁用户（reason必填）

POST /admin/users/{user_id}/unban?reason=解封原因
# 解封用户（reason可选）
```

### 11.3 店铺管理

```
GET /admin/shops?keyword=&page=1&page_size=20
# 店铺列表（含被封禁）

GET /admin/shops/{shop_id}
# 店铺详情（管理员）

POST /admin/shops/{shop_id}/ban?reason=违规
# 封禁店铺（reason必填）

POST /admin/shops/{shop_id}/unban?reason=解封原因
# 解封店铺（reason可选）

# 合并店铺
POST /admin/shops/merge?main_shop_id=1&duplicate_shop_ids=2,3
# main_shop_id=保留的主店铺, duplicate_shop_ids=逗号分隔的从属店铺ID
```

### 11.4 反馈管理

反馈类型：`complaint`（举报）/ `edit_request`（勘误）

```
GET /admin/feedbacks?type=&status=&page=1&page_size=20
# 反馈列表

POST /admin/feedbacks/{feedback_id}/approve
# 通过反馈

POST /admin/feedbacks/{feedback_id}/reject
# 驳回反馈
```

### 11.5 操作日志

```
GET /admin/logs?action=&target_type=&operator_id=&page=1&page_size=20
# 操作日志
```

### 11.6 公告

```
GET /admin/announcements?page=1&page_size=20
# 公告列表

POST /admin/announcements?title=标题&content=内容
# 发布公告
```

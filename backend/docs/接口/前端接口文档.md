## 1. 通用规范

### 1.1 认证方式

需要登录的接口在 Header 中传：

```
Authorization: Bearer <access_token>
```

登录后从返回的 `data.access_token` 获取 token。

### 1.2 响应格式

**成功：**
```json
{"code": 200, "message": "操作成功", "data": {...}}
```

**失败：**
```json
{"code": 422, "message": "验证失败", "detail": "具体错误"}
```

**未登录：**
```json
{"code": 401, "message": "请先登录后再进行操作"}
```

### 1.3 分页参数

列表接口统一支持：

| 参数 | 类型 | 默认 | 说明 |
|:---|:---|:---:|:---|
| `page` | int | 1 | 页码 |
| `page_size` | int | 20 | 每页条数（最大 100） |

分页响应：
```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "items": [...],
    "total": 50,
    "page": 1,
    "page_size": 20
  }
}
```

## 2. 用户模块

### 2.1 注册

```
POST /users/register
```

**Body：**
```json
{
  "username": "张三（字母/数字/下划线/中文，2-50位）",
  "password": "pass123（6-128位）",
  "phone": "13800138000（11位手机号）",
  "email": "user@example.com"
}
```

**返回：** `data` 为 [用户对象](#用户对象)

---

### 2.2 登录

```
POST /users/login
```

**Body：**
```json
{
  "type": "username",    // username / phone / email 三选一
  "account": "张三",     // 与 type 对应的值
  "password": "pass123"
}
```

**返回：**
```json
{
  "code": 200,
  "data": {
    "access_token": "eyJhbG...",
    "token_type": "bearer",
    "user": { /* 用户对象 */ }
  }
}
```

---

### 2.3 获取当前用户

```
GET /users/me
```

**Header：** `Authorization: Bearer <token>`

**返回：** `data` 为 [用户对象](#用户对象)。未登录时返回 `data: null`。

---

### 2.4 更新个人信息

```
PUT /users/me
```

**Header：** `Authorization: Bearer <token>`

**Body：（全部可选）**
```json
{
  "avatar": "头像URL",
  "bio": "个人简介",
  "gender": "male"   // male / female / other
}
```

---

### 用户对象

```json
{
  "id": 1,
  "username": "张三",
  "phone": "13800138000",
  "email": "user@example.com",
  "avatar": "URL或null",
  "bio": "简介或null",
  "gender": "male或null",
  "role": 0,
  "created_at": "2026-01-01T00:00:00"
}
```

## 3. 店铺模块

### 3.1 创建店铺

```
POST /shops
```

**Header：** 需登录

**Body：**
```json
{
  "name": "陈记糖水铺",
  "dict_data_ids": [1, 5],
  "menu_items": [
    {"name": "杨枝甘露", "price": 18.0, "description": "招牌"}
  ]
}
```

| 字段 | 必填 | 说明 |
|:---|:---:|:---|
| `name` | ✅ | 店铺名称 |
| `dict_data_ids` | ✅ | 品类ID和区域ID列表（至少一个品类+一个区域），从字典接口获取 |
| `menu_items` | ❌ | 初始菜单项 |

---

### 3.2 搜索店铺

```
GET /shops?keyword=糖水&page=1&page_size=20
```

**查询参数：**

| 参数 | 类型 | 说明 |
|:---|:---|:---|
| `keyword` | string | 搜索关键词（店铺名模糊匹配） |
| `category_ids` | int[] | 品类筛选（DictData ID 列表） |
| `district_ids` | int[] | 区域筛选（DictData ID 列表） |
| `min_rating` | float | 最低评分筛选（0-5） |
| `sort_by` | string | `favorite_count`/`average_rating`/`view_count`/`created_at` |
| `sort_order` | string | `asc` / `desc` |
| `page` | int | 页码 |
| `page_size` | int | 每页条数 |

**返回：**

```json
{
  "items": [
    {
      "id": 1,
      "name": "陈记糖水铺",
      "average_rating": 4.5,
      "view_count": 100,
      "favorite_count": 20,
      "comment_count": 10,
      "cover_image": "URL或null",
      "dict_data": [{"id": 1, "name": "糖水"}],
      "is_favorited": false,
      "created_at": "2026-01-01T00:00:00"
    }
  ],
  "total": 1, "page": 1, "page_size": 20
}
```

---

### 3.4 评分

```
POST /shops/{shop_id}/rating
```

**Header：** 需登录

**Body：**
```json
{"score": 4}
```

---

### 3.5 菜单

```
GET  /shops/{shop_id}/menu      # 获取菜单
POST /shops/{shop_id}/menu      # 添加菜品（需登录）
```

添加菜品 Body：
```json
{"name": "杨枝甘露", "price": 18.0, "description": "招牌甜品"}
```

---

### 3.6 更新/删除店铺（管理员）

```
PUT    /shops/{shop_id}
DELETE /shops/{shop_id}
```

更新 Body：
```json
{
  "name": "新店名",
  "dict_data_ids": [1, 5],
  "is_active": true
}
```

---

### 3.7 收藏

```
# 切换收藏
POST /favorites/toggle?shop_id=1
# 需登录，返回 {"is_favorited": true, "favorite_count": 10}

# 收藏列表
GET /favorites/user?page=1&page_size=20
# 需登录，返回带店铺名的收藏列表
```

## 4. 互动模块

### 4.1 评论

```
POST  /shops/{shop_id}/comments          # 发表评论
GET   /shops/{shop_id}/comments          # 评论列表
PUT   /comments/{comment_id}             # 更新评论
DELETE/comments/{comment_id}             # 删除评论
POST  /comments/{comment_id}/replies     # 回复评论
GET   /comments/{comment_id}/replies     # 回复列表
DELETE/replies/{reply_id}                # 删除回复
```

**发表评论 Body：** `{"content": "好吃！"}`

**回复评论参数：** `content` + `reply_to_user_id`（可选，用于 @username 前缀）

---

### 4.2 问答

```
POST  /shops/{shop_id}/questions          # 提问
GET   /shops/{shop_id}/questions          # 问题列表
PUT   /questions/{question_id}            # 更新问题
DELETE/questions/{question_id}            # 删除问题
POST  /questions/{question_id}/answers    # 回答
GET   /questions/{question_id}/answers    # 回答列表
DELETE/answers/{answer_id}                # 删除回答
```

**提问参数：** `title`（必填）+ `content`（可选）

---

### 4.3 点赞

```
POST /likes/toggle
```

**Body：**
```json
{"entity_type": "shop_comment", "entity_id": 1}
```

| entity_type | 说明 |
|:---|:---|
| `shop_comment` | 一级评论 |
| `shop_question` | 一级问题 |

**返回：**
```json
{"is_liked": true, "like_count": 5}
```

## 6. 字典模块

### 6.1 获取所有字典类型

```
GET /dict/types
```

**返回：**
```json
[
  {"id": 1, "name": "品类", "target_table": "shops"},
  {"id": 2, "name": "区域", "target_table": "shops"}
]
```

### 6.2 获取字典类型详情（含数据项）

```
GET /dict/types/{type_id}
```

### 6.3 按类型名称查字典数据

```
GET /dict/data?type_name=品类
```

**返回：**
```json
[
  {"id": 1, "name": "火锅"},
  {"id": 2, "name": "小吃快餐"}
]
```

## 9. 管理员模块

所有接口需管理员权限。

### 6.1 仪表盘

```
GET /admin/overview
# 返回：{total_shops, total_users, total_comments, pending_complaints, avg_rating...}

GET /admin/daily-trends?days=7
# 返回每日新增趋势数据

GET /admin/pending-counts
# 返回：{pending_complaints, pending_edit_requests}
```

### 6.2 用户管理

```
GET    /admin/users?keyword=&is_banned=&page=1

POST   /admin/users/{user_id}/ban?reason=违规内容
POST   /admin/users/{user_id}/unban
```

### 6.3 店铺管理

```
POST /admin/shops/{shop_id}/ban?reason=违规
POST /admin/shops/{shop_id}/unban

# 合并店铺
POST /admin/shops/merge?main_shop_id=1&duplicate_shop_ids=2,3
# main_shop_id=保留的主店铺, duplicate_shop_ids=逗号分隔的从属店铺ID
# 合并后从属店铺的数据（评论/评分/收藏/图片/菜单等）迁移至主店铺
```

### 6.4 举报管理

```
GET    /admin/complaints?status=pending
POST   /admin/complaints/{id}/approve?action=delete_comment&result_description=
POST   /admin/complaints/{id}/reject
```

`action` 可选值：`delete_comment` / `ban_shop` / `remove_image` / `dismiss`

### 6.5 勘误管理

```
GET    /admin/edit-requests?status=pending
POST   /admin/edit-requests/{id}/approve
POST   /admin/edit-requests/{id}/reject
```

### 6.6 操作日志

```
GET /admin/logs?action=&target_type=&operator_id=&page=1
```

### 6.7 公告

```
POST /admin/announcements?title=标题&content=内容
```

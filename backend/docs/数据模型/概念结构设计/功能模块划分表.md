# 功能模块划分表

| 模块名称 | 负责人 | 依赖模块 | 主要功能 |
|----------|--------|----------|----------|
| 用户模块 | 用户服务团队 | - | 用户注册、登录、资料更新、封禁解封、消息通知等 |
| 店铺模块 | 店铺服务团队 | 用户模块 | 店铺创建、搜索、更新、删除、合并、菜单管理、评分等 |
| 互动模块 | 互动服务团队 | 用户模块、店铺模块 | 评论、回复、问答、回答、点赞等 |
| 图片模块 | 媒体服务团队 | 用户模块、店铺模块 | 图片上传、查询、关联等 |
| 浏览历史模块 | 数据服务团队 | 用户模块、店铺模块 | 浏览记录、收藏、动态等 |
| 治理模块 | 内容审核团队 | 用户模块、店铺模块 | 反馈提交、审核、驳回等 |
| 管理员模块 | 系统运维团队 | 所有模块 | 平台概览、用户管理、店铺管理、反馈处理、公告发布等 |
| 数据分析模块 | 数据分析团队 | 所有模块 | 统计分析、趋势预测等 |

## 模块职责说明

- **用户模块**: 提供用户账户管理功能，包括注册、登录、资料更新、封禁解封等。
- **店铺模块**: 提供店铺信息管理功能，包括店铺创建、搜索、更新、删除、合并、菜单管理、评分等。
- **互动模块**: 提供用户与店铺之间的互动功能，包括评论、回复、问答、回答、点赞等。
- **图片模块**: 提供图片资源管理功能，包括图片上传、查询、关联等。
- **浏览历史模块**: 提供用户浏览行为记录功能，包括浏览记录、收藏、动态等。
- **治理模块**: 提供平台内容治理功能，包括反馈提交、审核、驳回等。
- **管理员模块**: 提供平台管理功能，包括平台概览、用户管理、店铺管理、反馈处理、公告发布等。
- **数据分析模块**: 提供平台数据分析功能，包括统计分析、趋势预测等。

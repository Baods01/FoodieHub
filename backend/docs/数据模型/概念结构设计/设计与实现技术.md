# 设计与实现技术

## 1. 应用逻辑编写

应用逻辑（业务逻辑）编写在 `services/` 目录下，例如 `UserService` 负责用户相关操作。每个 Service 类负责一个或多个相关的业务功能，如：

- `UserService`: 用户注册、登录、更新资料、封禁解封等
- `ShopService`: 店铺创建、搜索、更新、删除、合并、菜单管理、评分等
- `CommentService`: 评论创建、更新、删除、回复、点赞等
- `QuestionService`: 问答创建、更新、删除、回答、点赞等
- `FeedbackService`: 反馈提交、审核、驳回等
- `LogService`: 操作日志记录
- `FavoriteService`: 收藏切换、列表查询
- `MessageService`: 消息通知发送、读取、清空等
- `DictService`: 字典类型和数据的增删改查
- `HistoryService`: 浏览历史记录的增删改查
- `AnalyticsService`: 数据分析统计
- `LikeService`: 统一处理点赞逻辑（分发到对应 Service）
- `ActivityService`: 动态生成和查询

这种分层架构使得业务逻辑清晰、易于维护和测试。

## 2. 应用服务器工作

应用服务器使用 Uvicorn，配置在 `main.py` 中：

```python
from fastapi import FastAPI
from routers import (
    users, shops, interaction, history, images, governance,
    admin, activities, messages, dict_, complaints, analytics
)

app = FastAPI()

# 注册路由
app.include_router(users.router, prefix="/users", tags=["用户模块"])
app.include_router(shops.router, prefix="/shops", tags=["店铺模块"])
app.include_router(interaction.router, prefix="/interaction", tags=["互动模块"])
app.include_router(history.router, prefix="/history", tags=["浏览历史模块"])
app.include_router(images.router, prefix="/images", tags=["图片模块"])
app.include_router(governance.router, prefix="/governance", tags=["治理模块"])
app.include_router(admin.router, prefix="/admin", tags=["管理员模块"])
app.include_router(activities.router, prefix="/activities", tags=["动态模块"])
app.include_router(messages.router, prefix="/messages", tags=["消息通知模块"])
app.include_router(dict_.router, prefix="/dict", tags=["字典模块"])
app.include_router(complaints.router, prefix="/complaints", tags=["举报模块"])
app.include_router(analytics.router, prefix="/analytics", tags=["数据分析模块"])

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

Uvicorn 是高性能的 ASGI 服务器，支持异步请求处理，适合高并发场景。

## 3. 数据库访问实现

数据库访问通过 Tortoise ORM 实现，连接池配置在 `config.py` 中：

```python
DATABASE_URL = os.getenv("DATABASE_URL", "sqlite+aiosqlite:///./foodiehub.db")
DATABASE_POOL_SIZE = int(os.getenv("DATABASE_POOL_SIZE", "5"))
DATABASE_MAX_OVERFLOW = int(os.getenv("DATABASE_MAX_OVERFLOW", "5"))

```

Tortoise ORM 是异步 ORM，支持 PostgreSQL、MySQL、SQLite 等多种数据库，提供强大的查询能力和关系映射能力。

## 4. 三层架构/框架实际作用

采用 Controller → Service → DAO 的分层架构：

- **Controller (Router)**: 路由层，接收 HTTP 请求，调用 Service 层进行业务处理。
- **Service**: 业务逻辑层，处理具体业务，调用 DAO 层进行数据操作。
- **DAO**: 数据访问层，负责数据库交互，封装数据库操作。

这种分层架构使得代码结构清晰、职责分明，便于团队协作开发和后期维护。

### 示例：用户模块的分层架构

**Controller (Router)**:
```python
@router.post("/register", response_model=ResponseModel[UserResponse], summary="用户注册")
async def register(data: UserCreate):
    try:
        user = await UserService.register(data)
        return ResponseModel.success(data=user, message="注册成功")
    except ValueError as e:
        raise HTTPException(status_code=status.HTTP_400_BAD_REQUEST, detail=str(e))
```

**Service**:
```python
class UserService:
    @staticmethod
    async def register(data: UserCreate) -> UserResponse:
        dupe = await UserDAO.check_duplicate(data.username, data.phone, data.email)
        if dupe:
            labels = {"username": "用户名", "phone": "手机号", "email": "邮箱"}
            raise ValueError(f"{labels.get(dupe, dupe)}已存在")

        hashed = hash_password(data.password)
        user = await UserDAO.create(
            username=data.username, password=hashed,
            phone=data.phone, email=data.email,
        )
        return UserResponse.model_validate(user)
```

**DAO**:
```python
class UserDAO:
    @staticmethod
    async def create(username: str, password: str, phone: str, email: str) -> User:
        return await User.create(
            username=username, password=password,
            phone=phone, email=email,
        )
```

这种分层架构使得业务逻辑清晰、易于维护和扩展。

# 食探社 — 功能模块划分

## 功能模块划分表

| 模块名称 | 子功能 | 设计实现思路（简练，每模块50-100字） |
|----------|--------|--------------------------------------|
| 店铺信息管理模块 (FD01) | 创建店铺、上传图片/菜单、提交勘误反馈、提交重复店铺反馈 | 用户通过极简字段创建店铺，系统自动审核上线；用户可上传图片和菜单丰富信息；管理员处理勘误和重复反馈，确保数据质量。 |
| 点评与问答互动模块 (FD02) | 浏览点评与问答、店铺评分、发表图文评论、发布问答、回复问答、评论点赞 | 用户可查看店铺评分和讨论内容；支持对店铺评分、发表图文评论、提问和回答；点赞机制鼓励优质内容，形成社区互动闭环。 |
| 用户账户与收藏管理模块 (FD03) | 用户注册与登录、查看个人资料、修改个人信息、用户动态聚合展示、收藏/取消收藏店铺、查看收藏夹、查看消息通知、查看浏览历史记录 | 用户可通过邮箱或手机号注册登录；个人资料展示与修改功能完善；动态聚合展示用户行为；收藏和消息功能提升用户体验。 |
| 店铺发现与检索模块 (FD04) | 浏览店铺列表、关键词搜索店铺、分类与区域筛选、查看店铺详情 | 提供多种排序方式和筛选条件，帮助用户快速找到目标店铺；详情页展示完整信息，包括评分、评论和问答区。 |
| 社区反馈与举报模块 (FD05) | 举报不当内容 | 用户可针对评论、店铺或图片发起举报，系统拦截重复举报，确保举报有效性。 |
| 管理员后台治理模块 (FD06) | 处理举报反馈、处理勘误反馈、合并重复店铺、封禁/解封店铺、封禁/解封用户、发布系统公告、查看平台数据概览 | 管理员统一处理举报和勘误请求；执行店铺合并操作；维护平台秩序，发布系统公告并监控平台运营数据。 |

## 模块调用关系说明

1. **用户模块**（FD03）是所有功能的基础，提供用户认证和资料管理。
2. **店铺信息管理模块**（FD01）负责店铺的创建和基础信息维护。
3. **点评与问答互动模块**（FD02）允许用户参与社区互动，是核心社交功能。
4. **店铺发现与检索模块**（FD04）辅助用户发现和查找店铺。
5. **社区反馈与举报模块**（FD05）保障社区内容健康，处理违规内容。
6. **管理员后台治理模块**（FD06）是平台的管理中枢，负责数据质量和平台运营。

各模块间存在清晰的数据流和调用关系：用户行为触发动态生成，用户互动产生评论和点赞，举报和勘误由管理员处理，最终所有操作均记录在日志中。
